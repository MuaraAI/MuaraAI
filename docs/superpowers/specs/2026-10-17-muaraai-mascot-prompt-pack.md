## 9. Animation Quality Checklist

- First and last frames match closely enough to loop.
- Face, hair, hands, and prop do not morph.
- No camera movement is required.
- No newly generated text or symbols appear.
- No background is invented.
- Motion is subtle enough for a dashboard or empty state.
- Animation can be paused or replaced for `prefers-reduced-motion`.
- Static PNG fallback remains usable when animation is disabled.
- Export has transparency if supported; otherwise use the same neutral surface as the target UI.
- Produce a web-friendly format such as WebM or Lottie only after verifying the target integration. Keep the approved PNG as the source of truth.
